## 当前首屏与内容边界

本轮按用户选定的 [Dingxin Tao 作品集](https://github.com/DingxinTao0417/tdx-portfolio)首屏实现改装：双栏比例、方形仪表展示框、四角标记、顶部与右侧刻度尺、扫描入场、准星光标、Aurora 与网格拖尾保留其来源与机制，配色、文案和内容入口接入 SANSPHASE。左侧只保留介绍和两个主要动作，按钮下方留白。

粒子使用原作者的 GPGPU／shader 引擎、变形、鼠标扰动、拖动惯性、点击冲击波和滚动散开机制，没有继续使用上一轮 Bruno 像素粒子实现。三个静止目标分别为「影像引擎」「知识归档」「無相」：影像形态改为有实体机身、厚胶片轮与向前伸出镜筒的摄影机；知识形态改为有侧板、柜体与错开抽屉的立体档案柜，替换薄胶片框与书页。模型表面使用 Three.js `0.186.0` 自带 `CylinderGeometry`、`TorusGeometry`、官方 `RoundedBoxGeometry`／`ExtrudeGeometry` 和 `MeshSurfaceSampler` 采样；沿用其顶点法线和权重采样区分前面、侧面与背面，避免重叠表面成为等深的噪点。第三者仍通过原作者的文字采样器生成坐标，保留原有字形和厚度。全部目标交给同一引擎；目标造型与内容绑定是本项目适配，不能称为未经修改的第三方成品，也不使用生成图片或新增粒子算法。

「影像引擎」对应现有 AI 短视频工作流整理文章；「知识归档」对应个人知识库完成文章。初始播放沿用原作者的自动循环；点击画面、按回车或使用左右方向键可以切换，拖动用于旋转，拖动不触发点击换形。手动选择后停留在该内容，不会被随后自动轮播覆盖。文章阅读入口随实际形态同步；品牌态没有伪造的文章入口。`tests/scene-shapes.test.mjs` 校验确定性、扫掠边界、主体厚度、实体轮廓和前后表面明暗差；`scene-control` 与 `hero-scene-ui` 用例继续验证原控制和真实文章绑定。

HUD 的粒子数量、FPS、运行模式和变形进度来自当前引擎状态，加载时显示未知值，不能把原作的演示数据当成本机实测。正常加载不展示静态备用图或品牌大字，准备完成后直接进入粒子画面。暂停、离开首屏、后台标签页与减少动效偏好均由统一生命周期处理；仅在 GPU 等实际失败时显示静态备用画面并保留真实文章入口，晚到的成功回调不能覆盖失败状态。

绘制与输入分别处理：放大的粒子画布不接收鼠标事件；独立的原生按钮位于 HUD 框内，点击、拖动和键盘事件由它接收，坐标仍按原作画布投影。框外留白继续响应背景，不触发换形。背板使用原作 `HeroSection → useSpotlight` 的鼠标遮罩网格，以及独立的 64px 格子拖尾；只有底纹渐隐，拖尾不额外套入顶部遮罩。按用户要求移除鼠标旁 X/Y 坐标文字，保留准星与吸附；明确标注语义的入口仍使用文字标签。展示框底部的 X/Y 读数不在本次移除范围内。

当前公开内容来自原站 2026-10-17 快照中的四篇记录；网站建设没有已发布文章，不补造项目、资历或统计数字。英文保留为翻译草稿。首屏至第四幕、原有宣言及首页后半段的社区、发表日志、文章卡片、栏目索引、联系横幅和页脚均已接入相应交互；站内路径及其他页面的内容基础继续沿用现有实现，导航与转场的生命周期修复见下文。这是本地首页实现范围的完成记录，实际浏览器验收仍在进行，不代表全站重新设计或视觉已经超过参考站。正式站账号、权限、VIP、作者管理与生产数据不属于本演示。

## 鼠标命中与背景清理

准星、吸附框、64px 网格与 Aurora 造型继续使用既有 TDX 适配。命中先取最近的实际操作，外层的「拖动」区域不再盖住内部阅读链接和前后按钮；粒子输入保留「点击 · 拖动」提示，大尺寸文章与栏目链接分别显示阅读／打开语义，信息卡不显示虚构的点击操作。捕获拖动时按实际指针位置判断目标；滚动、目标位移和导航条过渡期间重新确认吸附。指针与目标稳定后停止自定义光标帧循环，原生输入时也不维持空转。

原有 `[data-magnetic]` 按钮交给 `src/magnetic.ts` 单次事件委托，不为动态重建的按钮重复绑定；沿用既有入点填色和指针牵引比例，缓存未移动的布局矩形并限制偏移，避免读取自身位移形成反馈。滚动、离开、取消、键盘输入、失焦、覆盖层、动态减少动效／粗指针和目标被移除时恢复原样；恢复活动后等待新鼠标输入，不重放旧坐标。

离开首屏边界、失焦、暂停或覆盖层出现时清除背景指针和追光。系统光标移交时立即隐藏自定义光标，避免淡出残影。上述状态、语义和调度属于本项目对已有第三方效果的适配与修复，不能描述成「零 AI 编写代码」或全部未经修改的现成组件。回归使用可控制的 DOM / 动画替身；实际浏览器证据单独保存，不能把替身中的必现条件等同于用户设备上每次必现。

## 导航、语言与路由生命周期

`src/header.ts` 从固定 TDX 提交的 `use-header-scroll`、`Navbar` 与 `LocaleSwitcher` 提取原生 DOM 适配。保留离顶 24px 收拢、160px 后自动隐藏、向下累计超过 14px 隐藏和向上超过 8px 显示的门槛；鼠标到顶部 32px 区域可临时唤回，离开 132px 区域就收回，不需要再滚动一次。键盘焦点与展开菜单保持导航可见；减少动态偏好禁用自动隐藏。EN / 中 各自是原生选择按钮，点击当前语言不会反转语言或重建内容，桌面与菜单的选中状态同步。命令面板的「切换语言」动作仍按原用途反转语言。

`src/page-transition.ts` 沿用源 `PageTransition` 与 `globals.css` 的上移退出、底部裁切进入：旧页向上 2.5rem、缩至 0.985 并淡出 260ms；新页由下方 3.5rem 和 `inset(100vh 0 0 0)` 揭开，延迟 40ms、时长 600ms。源曲线通过已安装 GSAP 的 `CustomEase` 适配，主题圆形切换独立运行。快速连续导航只允许最后一次请求更新页面；被替换的任务明确结束，晚到的旧动画回调不清理新页面。首次进入和减少动态状态即时切换。这里迁移的是呈现机制，没有增加 React、Motion 或第二套应用运行时，也不声称与上游截图转场逐字等同。

阅读器的首次揭示由本地 `src/reader-reveal.ts` 统一调度。文章已经准备、尚未到下一帧揭示时，也占有阅读器、背景 inert 与滚动锁状态；新的页面或文章请求会取消旧揭示，释放应释放的状态，避免过期文章在导航后重新出现或夺取焦点。首次直接打开文章期间维持滚动锁，实际阅读器与真实文章路径继续复用原实现。第三幕侧卡按钮变成正面链接时，把原有舞台焦点交给新链接并重算暂停门；语言刷新保留可用焦点，暂停或 inert 的轮播不从弹层和外部控件取回焦点。

`src/marquee.ts` 迁出原有跑马灯计算，速度、skew、循环和 0.15 悬停比例保持原值；参考源 `VelocityMarquee` / `useInViewport`，用 IntersectionObserver 观察静止父容器并缓存可见性。尚未确认可见或离屏时，`update()` 不读布局、不写样式；离屏清除悬停慢速，返场从原位正常推进。页面、失焦、弹层和减少动态的暂停继续由全局活动门处理，未引入逐帧布局轮询；不支持 IntersectionObserver 的客户端保留此前运行方式。销毁时断开观察和事件，晚到回调无效。在系统中开启「减少动态效果」后，还会停止并清理普通页面正文的分组入场，即使外层路由揭示已经结束，也不会留下仍在移动或半透明的正文。

原始源文件的字节数、SHA-256、Git blob、固定提交和本地修复边界见 `SOURCES.json.navigationLifecycleUI`。`fetch-provenance.json` 提供下载记录，`github-file-tree.json` 只提供路径；本轮另从既有核验仓库运行固定提交的 `git ls-tree`，逐项对照由原始字节计算的 Git blob。快速导航归属、阅读器取消及焦点修复是本项目接入工作，不能冒称原作未经修改的实现。本节新增行为的桌面浏览器结果由独立证据记录；此前截图与自动化测试不能代替本轮浏览器验收，也没有据此宣称实机性能提升或视觉超过参考站。
