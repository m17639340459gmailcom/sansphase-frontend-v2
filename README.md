## Install and verify

Use Node 24.21.x and official npm. From a clean checkout:

```text
npm ci
npm ci --prefix previews/hero-upgrade
npm run check:types
npm run build
npm test
```

Both lock files must stay committed. Root npm overrides retain the two CompressorJS transitive versions already reviewed in the upstream lock. The root lock was generated by official npm with install scripts disabled and its complete four-package integrity set checked against the frozen upstream lock. Frontend npm ci must permit esbuild's normal installation step. Never install the upstream full Payload dependency tree in this repository.

Build output is outputs/hero-upgrade/; generated output is ignored. npm run dev starts the existing loopback visual preview. It is **not** a production business server. Demo content is retained solely for isolated visual preview and regression; a same-origin integrated runtime must never replace a failed real API response with demo content.

## Runtime integration and switching

The integrated frontend requires the original same-origin /api endpoints, real session cookies, media permissions, Tianai login verification assets/service and original community handoff. The host must inject the checked #site-integration configuration. VIP frame art and other business assets remain served by the original host. Login, upload, email, VIP authorization, admin and community are not standalone static features. No token, API hostname or secret belongs in this frontend repository.

Production assembly and frontend switching stay in the upstream site repository: retain V1 under /original (shortcut /v1), the original /admin-console/, community services and immutable versioned assets. Select SITE_FRONTEND=v2 only through the original audited delivery pipeline; switch back with SITE_FRONTEND=v1 without moving persistent data. This independent build does not replace that pipeline and does not deploy by itself.

The copied docs/FRONTEND-* and preview acceptance documents describe the upstream integration and historical checks. Their references to original server, local snapshot launchers or private receipts do not mean those files or data are shipped here. Use the commands above for this standalone source checkout.
